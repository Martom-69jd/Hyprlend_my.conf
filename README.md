# Hyprlend_my-config 

Russian -


Это репозиторий с моей конфигурацией для Hyprlend и Noctalia-Shell v4.

Коротко
- Конфигурация предназначена для быстрой настройки рабочего окружения на базе Hyprland/Hyprlend и оболочки Noctalia-Shell v4.

Требования
- Hyprlend/Hyprland
- Noctalia-Shell v4
- Поддерживаемые зависимости (wayland, wlroots и др.) — см. документацию Hyprland/Noctalia.

Установка
1. Склонируйте репозиторий:
   git clone https://github.com/Martom-69jd/Hyprlend_my.conf.git
2. Перенесите нужные файлы конфигурации в соответствующие директории (например, ~/.config/hypr/ и ~/.config/noctalia/).
3. Перезапустите Hyprland/сессию или примените конфигурацию.

Использование и кастомизация
- Файлы конфигурации можно редактировать под свои нужды. Резервные копии оригиналов рекомендуются перед заменой.
- В README каждого отдельного файла (если добавлю) будут указаны конкретные параметры и примеры.

Поддержка
- Если что-то не работает, создайте issue с описанием окружения (дистрибутив, версии Hyprland/Noctalia, логи).

Лицензия
